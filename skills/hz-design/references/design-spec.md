# hz 设计规范 v1.1

更新于 2026-10-27。适用于图文、视频、官网落地页和桌面端产品。

---

## 1. 品牌定位

hz 是一个把 AI 讲清楚、讲明白的靠谱向导，讲得专业，也讲得有意思。

| 项目 | 内容 |
| --- | --- |
| IP 名称 | hz（固定小写，不写成 HZ 或 Hz） |
| 内容方向 | AI 科普、技术分享 |
| 目标受众 | 想学习 AI 的学生和职场人 |
| 品牌关键词 | 靠谱（最重要）、有趣 |
| 呈现方式 | 纯图文，不露面 |
| 发布平台 | 小红书、B 站、公众号、抖音 |
| 口号（建议，待确认） | 慢慢讲，讲明白 |

**核心比例：靠谱是底色，有趣是点缀。** 视觉上约 80% 冷静、清晰、有秩序，20% 留给品牌紫、圆体标题和对话气泡。拿不准时，选更克制的那个。

## 2. 设计原则

方向是“清爽理性”：白底、黑字、一个品牌紫。学苹果的原则，不学苹果的外观。

1. **留白优先**：信息不拥挤，画面越空，内容越好懂。
2. **颜色克制**：黑白灰为主，只用品牌紫引导视线。紫色一出现，就是“这里重要”。
3. **层级分明**：任何画面都能一眼看出先看什么、再看什么。
4. **细节统一**：圆角、间距、字重只用规范里的值，不随手改。
5. **平面纯色**：不用渐变、发光和重阴影，和常见的“AI 紫”风格拉开距离。

## 4. 字体与排版

只有标题用圆体，其余全部用黑体。所有字体均可免费商用；苹方、微软雅黑仅作系统回退，不用于导出的图片和视频。

### 4.1 字体搭配

| 用途 | 中文 | 英文与数字 |
| --- | --- | --- |
| 大标题、封面标题、官网首屏 | 资源圆体 | Nunito |
| 正文、按钮、界面、字幕 | 思源黑体（Noto Sans SC） | Inter |
| 代码、提示词原文、快捷键 | 思源黑体 | JetBrains Mono |

字重只用 Regular 400、Medium 500、Bold 700。Bold 只给圆体标题。资源圆体不在 Google Fonts，网页上线需自托管。

| --- | --- | --- | --- |

### 4.4 中英混排

1. 中文与英文、数字之间加一个空格：“用 ChatGPT 写 3 段文案”
2. 专有名词保留官方写法：ChatGPT、Midjourney、hz
3. 强调只用加粗或品牌紫二选一，不用下划线、斜体，也不叠加
4. 正文左对齐，一行不超过 40 个汉字

## 5. 基础规则

### 5.1 圆角

| 变量 | 值 | 用于 |
| --- | --- | --- |
| --radius-sm | 6px | 标签、复选框、快捷键提示 |
| --radius-md | 10px | 按钮、输入框、菜单项 |
| --radius-lg | 16px | 卡片、图片、弹窗、对话气泡 |
| --radius-full | 999px | 头像、开关、圆点 |
| --radius-bubble | 16px 16px 16px 4px | 讲解气泡（左下尖角） |
| --radius-bubble-user | 16px 16px 4px 16px | 提问气泡（右下尖角） |

### 5.2 间距

以 4 为基数，只用 4、8、12、16、24、32、48、64、96。

- 组件内部（图标与文字）：8
- 表单项、列表项之间：12–16
- 卡片内边距：24（桌面端紧凑 16）
- 模块之间：48（桌面端 32）
- 官网大段落之间：96（移动端 64）

### 5.3 图标

线性，线宽 1.5px，圆头。用 Lucide（首选）或 Tabler，一个产品只用一套。尺寸 16 / 20 / 24。默认 --text-secondary，选中 --brand-text。

### 5.4 阴影

层次优先靠背景色和 1px 边框，阴影只给浮起的元素。

| 变量 | 值 | 用于 |
| --- | --- | --- |
| --shadow-sm | 0 1px 2px rgba(28,28,35,0.06) | 悬停中的卡片 |
| --shadow-md | 0 4px 16px rgba(28,28,35,0.08) | 菜单、下拉 |
| --shadow-lg | 0 12px 40px rgba(28,28,35,0.12) | 弹窗、命令面板 |

深色模式改用 --bg-elevated + 1px --border 表达层级。

### 5.5 动效

| 变量 | 值 | 用于 |
| --- | --- | --- |
| --duration-fast | 120ms | 悬停、按下 |
| --duration-base | 200ms | 菜单、开关、切换 |
| --duration-slow | 320ms | 弹窗、侧栏、页面过渡 |
| --ease-out | cubic-bezier(0.2, 0, 0, 1) | 进入、展开 |
| --ease-in-out | cubic-bezier(0.4, 0, 0.2, 1) | 位移、切换 |

气泡弹出：96% → 100% 缩放 + 淡入，200ms，以左下尖角为原点。尊重“减少动态效果”系统设置。

## 6. 品牌标志与对话气泡

对话气泡是 hz 的视觉记号，暗示“和 AI 对话”。

### 6.1 气泡形状

- 圆角左上、右上、右下 16px，左下 4px
- 尖角永远在左下；只有问答里的观众提问用右下尖角
- 纯色，不加阴影、描边、渐变

### 6.2 文字标志

小气泡 + hz。“h”用正文色，“z”用品牌紫。文件见 `assets/logo/`。

| 部分 | 浅色背景 | 深色背景 |
| --- | --- | --- |
| 小气泡 | #5A4BC6 | #7366D8 |
| h | #1C1C23 | #F7F7FA |
| z | #5A4BC6 | #B5ACF1 |

- 字体 Nunito Medium，字间距 -1%
- 气泡宽高比 5:4，与文字间距 = 气泡宽度的 1/3
- 安全距离：四周至少一个气泡宽度
- 整体宽度不小于 48px；更小场景只用小气泡
- 应用图标：紫色圆角方底，中间白色小气泡

### 6.3 对话气泡：只装“说出来的话”，不装标题

气泡代表“有人在说话”。它的意义来自少用：只在内容本身是一句问话、一句回答或一句结论时使用。**标题不放进气泡**，层级靠字号、字重和留白建立。

**可以用的地方**

| 场景 | 用法 |
| --- | --- |
| 真实对话 | 产品里的 AI 对话、问答卡片、视频里的问答段落。提问灰色气泡靠右，讲解紫色气泡靠左 |
| 内容封面与片头 | 封面主文案是一句问话或口语时（如“AI 为什么会胡说？”），可放进一个气泡；陈述式标题（如“提示词的三个秘诀”）直接用大字，不加气泡 |
| 重点结论 | 文章或幻灯片里的一句核心结论、金句，作为引用块；每页最多一处，可以不用 |

**不要用的地方**

- 网页、桌面端、幻灯片的标题和小标题（首屏大标题、区块标题、结尾号召标题）
- 卡片标题、按钮、导航、表格、标签
- 系列里的每一页都套：一个页面可以没有气泡，整个落地页只在产品示意和问答演示里出现

**样式**

- 讲解气泡：浅色底 #F4F3FD，深色底 #282160；提问气泡：--bg-muted。文字用正文色，不用紫色字
- 一个画面最多一个“主气泡”（封面或结论）；对话里成组出现的气泡不受此限
- 文字左对齐，内边距不小于文字高度的一半
- 视频里：气泡弹出 + 文字逐字打出，只用于问答段落和问句式片头

品牌辨识度主要靠标志里的小气泡、品牌紫和圆体标题，不靠在标题后面铺底色。

## 7. 组件规范

每个可交互组件做全五种状态：默认、悬停、按下、键盘焦点、禁用。焦点环 3px --focus-ring，只在 :focus-visible 时显示。

### 7.1 按钮

一个画面只有一个主按钮。文案动词开头，2–6 个字。

| 类型 | 默认 | 悬停 | 按下 | 用于 |
| --- | --- | --- | --- | --- |
| 主按钮 | --brand 底，白字 | --brand-hover | --brand-active | 每屏最重要的操作 |
| 次按钮 | 透明底，1px --border-strong | --bg-muted 底 | 缩放 98% | 取消、次要操作 |
| 文字按钮 | --brand-text | --brand-subtle 底 | 缩放 98% | 工具栏、行内 |
| 危险按钮 | #D9433F 底，白字 | 加深 8% | 加深 16% | 不可撤销操作 |

| 尺寸 | 高度 | 左右内边距 | 字号 |
| --- | --- | --- | --- |
| 小 | 28px | 10px | 13px |
| 中 | 36px | 16px | 14px |
| 大 | 48px | 24px | 16px |

### 7.2 输入框

高度同按钮档；--bg-page 底，1px --border，圆角 10px。悬停 --border-strong；聚焦 --brand 边框 + 焦点环；错误 #D9433F 边框 + 下方 12px 说明（发生了什么 + 怎么做）。占位符用真实示例。代码/提示词输入用 JetBrains Mono + --bg-subtle。

### 7.3 卡片

--bg-page + 1px --border，或 --bg-subtle 无边框，同页不混用。圆角 16，内边距 24（紧凑 16）。可点击卡片悬停：--border-strong + --shadow-sm，不上移。密集列表用分割线。

### 7.4 标签

高 22px，左右 8px，12px 字，圆角 6px。品牌标签：--brand-subtle + --brand-subtle-text；中性：--bg-muted + --text-secondary；状态：功能色浅底 + 文字色。

### 7.5 开关、复选、单选

选中 --brand 填充 + 白色勾/点；未选中 1px --border-strong。开关 36×20px。

### 7.6 反馈

| 组件 | 规则 |
| --- | --- |
| Toast | 底部居中或右下，--bg-elevated + --shadow-md，圆角 10，3 秒消失，文案过去式“已保存” |
| Banner | 功能色浅底 + 文字色，左侧 20px 图标 |
| Modal | 宽 480（大 640），圆角 16，内边距 24，遮罩 --overlay；按钮右对齐，主按钮最右 |
| Tooltip | #1C1C23 底白字 12px，圆角 6，悬停 500ms 出现 |
| 加载 | 优先骨架屏；转圈只用于按钮内和 1 秒内等待 |
| 空状态 | 线性插图 + 圆体标题 + 一句说明 + 一个主按钮 |

## 8. 桌面端应用规范

默认跟随系统深浅模式；“标题栏 + 侧栏 + 内容区”三段式。

| 区域 | 规格 |
| --- | --- |
| 最小窗口 | 960 × 640；默认 1280 × 800 |
| 标题栏 | 高 44，与侧栏同底色，可拖动 |
| 侧栏 | 宽 240，可收起到 64；--bg-subtle，右侧 1px --border |
| 内容区 | --bg-page，内边距 32；阅读内容最大 720 居中 |
| 右侧面板 | 宽 320，可选 |

- 导航项高 32，圆角 8；选中 --brand-subtle 底 + --brand-subtle-text 字
- 列表行高 36（带副标题 56），分割线分隔
- 菜单项高 32，右侧灰色快捷键
- AI 对话：回复靠左 --brand-subtle 左下尖角；用户靠右 --bg-muted 右下尖角；生成中末尾闪烁品牌紫光标；输入区固定底部，最小高 56
- 命令面板 ⌘K / Ctrl+K，宽 560；常用快捷键遵循系统习惯
- 危险操作先确认，可撤销操作直接执行并给“撤销”提示
- 设置里提供“外观：跟随系统 / 浅色 / 深色”

## 9. 官网落地页规范

默认浅色；整页只有一种主操作，反复出现。

| 断点 | 宽度 | 内容最大宽 | 边距 | 栏数 |
| --- | --- | --- | --- | --- |
| 桌面 | ≥ 1200 | 1120 | 居中 | 12 栏，间距 24 |
| 平板 | 768–1199 | 100% | 32 | 8 栏，间距 24 |
| 手机 | < 768 | 100% | 20 | 4 栏，间距 16 |

页面结构：导航栏（64 高）→ 首屏（圆体大标题，可一个词用品牌紫 + 说明 + 主/次按钮 + 产品截图，标题不加气泡底）→ 3 张能力卡片 → 图文交替详解 → 信任区（只用真实数据）→ 常见问题 → 深色结尾号召 → 页脚。

- 产品截图圆角 16 + --border + --shadow-lg，放在 --bg-subtle 大块上
- 区块之间只用背景色或留白分隔
- 滚动进入：上移 16 + 淡入，320ms，每屏一次
- 下载按钮识别系统，下方给其他系统入口
- 文字对比度至少 4.5:1

## 10. 内容平台规范

先做小红书 3:4 母版，主文案放画面中央，再裁出其他尺寸。

| 平台 | 尺寸 | 安全区要点 |
| --- | --- | --- |
| 小红书 | 3:4 · 1080×1440 | 四周留边距 |
| 抖音 | 9:16 · 1080×1920 | 网格裁成中间约 3:4；标题放中上部 |
| B 站 | 4:3 · 1200×900 | 标题放中间 16:9 区域 |
| 公众号头图 | 2.35:1 · 900×383（导出 1800×766） | 内容居中，中央方形可独立成立 |
| 公众号次条 | 1:1 | 只放主文案或小气泡标志 |

封面只有三层：期号（灰色小字）、主文案（≤2 行，每行 ≤8 字；问句可放进气泡，陈述句直接用大字）、小气泡 + hz 落款。

| 字幕 | 横屏 1920×1080 | 竖屏 1080×1920 |
| --- | --- | --- |
| 字体 | 思源黑体 Medium 白色 + 淡深色描边 | 同左 |
| 字号 | 约 48px | 约 56–64px |
| 位置 | 距底部约 8% | 下方 1/3 以上 |
| 高亮 | #B5ACF1，一句最多一个词 | 同左 |

片头：标题逐字打出，问句式标题可配气泡弹出，2 秒内。水印：右上小气泡 + hz，60% 不透明。片尾：标志 + 口号，2 秒。
